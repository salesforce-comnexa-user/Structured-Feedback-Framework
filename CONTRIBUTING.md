# Contributing

Create a focused branch, change the pack or renderer, and run the documented checks. Review both the user-facing page and JSON round trip. Keep customer results, evidence, credentials and local exports out of Git.

Pack content and expected-result changes require revision/version assessment; interface-only changes should preserve valid existing feedback. Use a pull request to describe the problem, resulting behavior, changed case IDs and actual validation. Follow the delivery owner's approval and publication process.

This initial repository has no open-source license grant. Distribution and reuse should follow the owner's internal policy; agree a license before publicly distributing repository source.
