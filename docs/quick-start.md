# Try the example

1. Clone or download this repository. Private-repository access is required to obtain the source.
2. Run `python3 scripts/build.py` from the repository root.
3. Open `dist/index.html` in a modern browser, or serve `dist` locally.
4. Enter a tester reference, such as `UAT-reviewer-01`.
5. Read a scenario. In this fictional example, explore the interface; for real UAT, execute the steps in the agreed configured sandbox.
6. Choose an outcome. Failed and Blocked require an actual result. Record feedback and an evidence reference if useful.
7. Add whole-story or whole-pack feedback where appropriate.
8. Select **Export feedback**. Keep the downloaded JSON and send it through the agreed project channel.
9. Use **Review an exported feedback file** to inspect the returned JSON. Import will not replace the draft you were editing.
10. Use **Print / save PDF** for a readable companion. JSON is the structured review record.

Drafts are scoped to project, release, pack and pack version in the browser profile. They are not shared with the team, synchronized across devices or separated automatically by tester reference. On a shared computer, export first, then use **Clear my local draft** before another tester starts. Different testers should return separate exports. Browser storage may be disabled or cleared; always keep the exported file.

Public example URL after successful Pages activation: `https://salesforce-comnexa-user.github.io/Structured-Feedback-Framework/`. A URL in this document is a proposed destination, not confirmation that deployment succeeded.
